# 📰 Fake News Detection Dashboard

An interactive dashboard for comparing Machine Learning models used in Fake News Detection.

## 🚀 Live Demo

https://fakenewsdetectiondashboard-k8srhped65rssy7uiqifdw.streamlit.app/

## 📌 Features

* Dataset Overview
* Fake vs Real News Distribution
* ML Model Comparison
* Performance Metrics Analysis
* Interactive Visualizations
* Best Model Identification

## 🤖 Models Evaluated

* Logistic Regression
* SVM
* Random Forest
* MLP
* KNN
* J48
* PART

## 📊 Metrics Used

* Accuracy
* Precision
* Recall
* F1 Score
* Cohen's Kappa

## 🛠 Technologies

* Python
* Streamlit
* Pandas
* NumPy
* Plotly

## ▶️ Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
